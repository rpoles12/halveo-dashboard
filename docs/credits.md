# Credits and provenance

## Project

Halveo is a fictional portfolio case by **Rafael Poles / Ruptive®**. The wider project covers strategy, naming, visual identity, physical applications, a working dashboard prototype and motion design. This repository packages the dashboard and a curated portion of that presentation material.

The development process used AI assistance for implementation, documentation and an abstract cover background. The app screenshots are captured from the actual production build. The cover uses the original SVG wordmark and real overview image over the generated background. The brand mark is not redrawn by the image model.

All organizations, facilities, people, source readings, anomalies, savings and reporting examples in the app are fictional.

## Software and typography

React, Vite, TypeScript, Apache ECharts, Motion, GSAP, Anime.js, Three.js, Lucide React, Playwright and their transitive dependencies remain subject to their respective published licences. The dependency lockfile records resolved package versions; this project does not replace or relicense their terms.

The interface requests **Schibsted Grotesk** from [Google Fonts](https://fonts.google.com/specimen/Schibsted+Grotesk). No font binary is redistributed in this repository. The app falls back to system sans-serif fonts if the external font is unavailable.
